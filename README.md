# PLE Baseline

This is a standalone starter harness for the Physical-Engineering's Last Exam
(PLE). It adapts the repository's `custom-openai` reference agent to the
competition entry layout:

- `submission.yaml` selects the sponsored `google-cloud/gpt-oss-120b` model.
- `serve.py` starts the PLE WebSocket protocol handler.
- `harness.py` contains the tool-using agent loop.
- `taskbridge.py` implements the task-side protocol and tool bridge.

The harness is intentionally a general-purpose baseline. It does not contain
engineering-specific calculation modules or task-specific answers.

## Validate

From the PLE repository environment, run:

```powershell
uv run python -m kit check C:\path\to\ple-baseline
uv run python eval\run.py C:\path\to\ple-baseline
uv run python -m kit artifacts C:\path\to\ple-baseline
```

`artifacts/` must be generated by `eval/run.py`; do not create placeholder
artifacts. Dev-set execution requires the PLE task data and a configured local
or personal model endpoint. Before submission, record the evaluated model and
judge setup and commit the generated, unpacked artifacts directory.
